## 暴跌紧急复盘模式的额外要求

第一节改为"先看结论：发生了什么，以及它意味着什么"，必须包含：
1. 行情性质判定（加密脱钩 or 宏观共振）+ 对既有论点的影响
2. 哪些关键防线被击穿（逐一对照上次报告点位）
3. 暴跌的直接触发因素（多因素列举：卖方事件、ETF 流向、爆仓数据等）
4. 诚实声明："前版多头论点现状：……"——被证伪就写被证伪

操作建议部分必须拆成两种情形：
- **若已按前版建多（已被套）**：按标的逐一给纪律性处理方案，不许摊平
- **若空仓等机会**：观察位 + 确认信号（双满足才进场）+ 右侧追多替代方案

仓位原则单列：总仓位压至平时 1/3 以下、拒绝接飞刀、小仓试探、ETF 流向作先行灯。
