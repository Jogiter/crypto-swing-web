# 加密波段综合分析 Skill（做多视角）

## 适用与边界

✅ **适用**：BTC / ETH / SOL 等大市值币种的波段分析；定期复盘（月线收线、周线收线）；暴跌/暴涨后的紧急复盘；入场时机评估
❌ **不适用**：小市值山寨币、合约高频策略、做空策略分析（用户为纯多头）、港股打新（用 hk-ipo-scoring）、A股定投（用 btcdca.me 公式流程）

## 用户画像（默认假设，除非用户更正）

- **风格**：波段交易（数天到数周），纯多头视角
- **主战周期**：4H 执行；日线/周线看背景；月线看宏观结构
- **指标体系**：加权评分制——SRSI 25分 / MACD 25分 / MFI 20分 / Volume 15分 / SuperTrend 15分，辅以 ADX；≥70 做多信号，≤30 离场信号（与其 Pine Script v2.2 对齐）
- **宏观关注**：美股板块整体（三大指数 + SpaceX/AI 公司 IPO 进展作为其中的风险偏好信号）+ 恐惧贪婪指数
- **核心纪律**：止损触发后禁止向下摊平，必须等右侧确认再重建仓位

## 执行流程（严格按序）

### 第 0 步：澄清（仅首次或情况不明时）

若对话中尚不清楚以下三项，先问（一次问完，不超过3个问题）：
1. 持仓周期（日内/波段/中长期）
2. 宏观代理具体指什么
3. 纯多头还是双向

若上下文/记忆已有答案，直接跳过，开始分析。

### 第 1 步：数据采集（一步一步，逐项核实）

**原则**：所有价格与指标必须来自当日实时检索，标注采集时间。**实时价格首选 Binance 公开行情数据或 Yahoo Finance（BTC-USD / ETH-USD / SOL-USD）实时数据**——可尝试用 bash 调取其公开 API（若网络允许），否则用 web_fetch 抓取其行情页或检索其数据；其次 CoinGecko、TradingView 公开页。链上与资金面用 Glassnode / Farside / DefiLlama / CoinGlass / colintalkscrypto（CBBI）。新闻文章只作辅证。**严禁使用训练记忆中的价格。**

按序检索（每步确认数据时效后再进行下一步）：
1. BTC 当前价格 + 关键事件（首选 Binance / Yahoo Finance 实时数据）
2. ETH 当前价格 + 支撑阻力（同上）
3. SOL 当前价格 + 支撑阻力（同上）
4. ETF 资金流（BTC/ETH 现货 ETF 日度/周度净流向——这是**先行指标**，必查）
5. 链上与周期估值核心指标（见第 4 步指标清单）：MVRV、CBBI、BTC 幂律位置、200周均线价格、LTH 供应变化、交易所储备、NUPL/SOPR、清算数据
6. 美股板块（含 IPO 风险偏好信号）：三大指数当日表现、SpaceX/AI 公司 IPO 进展、恐惧贪婪指数
7. 若为复盘：对照上次报告的关键点位，逐一核对是否触发

**数据冲突处理**：不同口径数据（如 LTH 供应两套统计）并列呈现并注明来源，不强行调和。

### 第 2 步：核心鉴别——下跌/上涨的性质判定（最关键的分析框架）

每次分析必须先回答：**这是加密专属行情，还是宏观共振？**

| 情形 | 特征 | 含义 | 应对 |
|---|---|---|---|
| **加密向下脱钩** | 加密大跌 + 美股走平/新高 | 加密内部资金外流/结构抛压，**不能**指望宏观缓解带来反弹 | 防御，等 ETF 流向反转 |
| **宏观 risk-off 共振** | 加密与美股同跌 | 外部冲击（地缘/通胀/加息），冲击缓解则同步修复 | 盯宏观催化剂，可在恐慌底分批 |
| **加密独立走强** | 加密涨 + 美股平 | 加密内部资金回流（ETF 转流入常为先导） | 顺势持有/加仓 |
| **风险偏好共振上行** | 同涨 | 最佳做多环境 | 正常执行多头策略 |

**实战教训（2026年6月验证）**："美股新高=风险偏好旺盛=加密终将补涨"的均值回归假设可被证伪——加密可以向下脱钩。背离的解决方向必须由 ETF 资金流向确认，不能预设。

### 第 3 步：多周期技术分析（每个币种 × 4 个周期）

每个币种给出：
- **4H**：支撑×2-3、阻力×2-3、指标状态（对齐用户的 SRSI/MFI/MACD/Volume/SuperTrend/ADX 体系）
- **日线**：支撑、阻力、RSI/均线位置（20/50/100/200日 EMA）
- **周线**：结构性支撑（如 BTC 200周均线）、生死线、大级别阻力
- **月线**：仅在月线收线复盘或大行情时展开；平时一句话带过结构

**点位质量要求**：每个点位需有依据（均线/前高前低/成本密集区/心理整数/斐波），不可凭空给数。来源数据冲突时取多源交叉验证的区间。

### 第 4 步：链上与资金面

- **ETF 流向放第一位**（先行灯）：连续流出=做多环境恶化；流出潮终止/转流入=环境改善第一信号
- **周期估值核心指标（必查清单，BTC 为主）**：
  - **MVRV / MVRV Z-Score**：>3 过热区、<1 历史底部区，标注当前读数与历史分位
  - **CBBI**（colintalkscrypto Bitcoin Bull Run Index）：综合周期指数，>90 周期顶部预警、<15 周期底部区
  - **BTC 幂律（Power Law）位置**：当前价格相对幂律支撑线/中轨/上轨的位置，幂律下轨历史上是强支撑
  - **200周均线价格**：报告其具体数值与当前价格的比值（价格/200周均线），历史上从未失守后不收复，是"数学底"
  - NUPL（乐观/投降区间判定）、SOPR（>1 盈利兑现 / <1 割肉）
- LTH 行为（积累/分销转变是重要拐点信号）
- 结构性买方地板状态（如 Strategy 持仓变动——注意：**象征意义可能远大于金额**，首次卖币哪怕32枚也能引发恐慌）
- 交易所储备、稳定币总量、清算热图
- SOL 额外：质押率、DEX 成交量（活动萎缩是基本面警讯）、原生计价 TVL、生态升级进度

### 第 5 步：美股与风险偏好（宏观板块）

美股信息统一归入本板块（IPO 是美股影响点之一，不再单列为独立代理）：
- **美股三大指数当日表现**（标普/纳指/道指）+ 关键科技股动向，并判定与加密的背离方向（衔接第 2 步的性质判定）
- **IPO 风险偏好信号**：SpaceX / OpenAI / Anthropic / Cerebras 等大型 IPO 的进展、定价、首日表现 → 成长风险偏好温度计；注意"流动性争夺"效应（AI 股吸金可能分流加密资金）
- **恐惧贪婪指数**（加密 F&G，必要时对照 CNN 美股 F&G）
- 美联储/通胀/美元/地缘油价

### 第 6 步：实操建议（做多视角）

每个币种输出：
- **方向偏好 + 信心等级**（高/中高/中/低，并说明较上次升降的原因）
- **入场区**（分批，标注理想加仓位）
- **多层止损**（4H 结构止损 → 最终止损；ETH 类弱标的需额外设周线生死线）
- **分批止盈**（TP1/TP2/TP3 各减仓比例，突破关键位转移动止盈）
- **风险回报比**（明确计算口径：入场/止损/目标）
- **仓位权重建议**（与信号强度和波动率挂钩）
- **加仓硬条件**（如"ETF 重回净流入 + 4H 放量翻多"，缺一不可）

**暴跌后的特殊协议**（任一关键止损被触发即启动）：
1. 诚实声明：哪些止损被触发、哪个论点被证伪——不粉饰
2. 基调切换为防御：总仓位压至平时 1/3 以下
3. **禁止建议向下摊平**；超卖≠见底，趋势性下跌中 RSI 可长期超卖
4. 分"已持仓如何处理"与"空仓等什么位置+什么信号"两种情形给建议
5. 重建多头需"位置+确认信号"双满足，信号至少含：ETF 流出潮终止、4H 放量企稳、SRSI 底背离金叉

### 第 7 步：动态触发阈值 + 关键日历

- **转进攻条件**（具体可验证，如"BTC ETF 连续3日净流入"）
- **转防御条件**（具体点位，如"BTC 周线失守 200周均线"）
- **关键日历**：IPO 定价日、美联储议息、CPI/PCE、期权到期、链上升级节点

## 输出格式

详见 `references/report-template.md`。要点：
- 简体中文 Markdown 文件（输出到 /mnt/user-data/outputs，文件名含日期）
- 开头：数据采集时间 + 数据来源声明 + TL;DR（≤3条核心结论）
- 复盘报告必须含**与上次对照速查表**（价格/资金面/论点状态/止损触发情况逐项对比）
- 结尾：风险提示（数据时效、不构成投资建议、本金风险），并提醒下单前实时二次确认
- 对话中的总结保持简短，重内容在文件里

## 红线（任何情况下不可违反）

1. 不使用训练记忆中的价格数据冒充实时数据
2. 不在止损触发后建议摊平或"再给一点空间"
3. 不把"超卖"单独作为入场理由
4. 复盘时不回避上次判断的错误——明确说"该逻辑被证伪"
5. 每个价格点位必须标注数据采集时间
6. 报告必须含免责声明
